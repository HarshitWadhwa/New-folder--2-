Hashing vs. Encoding

Encoding (e.g., Base64) is simply data representation designed for transmission, NOT security. Anyone can decode it instantly without a key.

Hashing is a one-way mathematical function designed to be irreversible ($y = H(x)$).

Mitigated

The Power of Cryptographic Salts

Without salt, identical passwords result in identical hashes. Attackers use Rainbow Tables (gigabytes of pre-computed hash lookups) to crack millions of passwords in milliseconds.

A unique Salt ensures every hash is globally unique, rendering Rainbow Tables completely useless.

Gold Standard

Work Factor & Slow Hashes

Fast hashes like MD5 and SHA-256 were designed for file checksums and can be computed at 100+ billion guesses per second on GPUs.

Password hashing requires adaptive slow algorithms (PBKDF2, bcrypt, Argon2) that force thousands of iterations, stopping brute-force botnets.
